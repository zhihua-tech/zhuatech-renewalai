# 知华续约预警 · 企业客户成功工作台

客户续约风险常常散落在使用率、服务工单和回款记录中。本项目把这些信号收拢到一个可审计的流程里：**合同激活 → 采集健康信号 → 风险评估 → 挽留计划审批 → 续签登记**。

由上海如静知华信息科技有限公司维护，官网 https://www.zhuatech.cn/ 。

## 功能与业务约束

| 模块 | 已实现能力 |
| --- | --- |
| 客户档案 | 客户分层、负责人、重复名称校验。 |
| 合同 | 有效期与金额校验、激活、风险状态、续签前后快照。 |
| 健康信号 | 按合同与日期登记席位利用率、未结工单和逾期金额；同日去重。 |
| 预警分析 | 本地规则对通知窗口、低利用率、服务压力、逾期回款评分，保存因素、建议与规则版本。 |
| 挽留及续签 | 高风险先提交计划，独立审核通过后由管理员登记新期限和金额；不能跳过审批。 |
| 管理 | 账号/角色、审计、租户隔离、附件、幂等、CSV 和 H5 工作台。 |

验收用例中的合同距到期 45 天，席位利用率 30%、未结工单 4 个且有逾期款，风险分数为 100。系统要求先批准挽留计划，才能登记续签；试图提前续签会被拒绝。

### 分析器扩展点

`backend/src/main/java/cn/zhuatech/renewalai/InsightProvider.java` 暴露评分接口。默认 `LocalInsightProvider` 使用**本地规则**，会产生可解释因素和建议，**没有真实大模型调用**。企业可另写适配器连接国内模型，但关键财务、日期和审批规则应继续由服务端验证。模型建议不得自动代替客户经理的判断。

## 运行

技术栈：Java 21、Spring Boot 4、MySQL 8.4、Vue 3；业务 H5 和管理端分离。先从 `.env.example` 创建 `.env` 并设置强密码，然后执行：

```bash
docker compose up -d --build
sh scripts/test.sh
```

H5 默认 `http://127.0.0.1:8088`，管理入口 `/admin`。测试脚本跑后端业务验收、前端单测和构建；本地后端采用 H2 的 MySQL 兼容模式，CI 配置 MySQL 测试。接口可从 `GET /api/catalog` 查看；`POST /api/records/{id}/actions/evaluate` 触发评估。生产请自行补充 CRM、工单和财务系统数据对接及数据质量校验。
